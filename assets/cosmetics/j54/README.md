# J-54's look (cosmetics)

Ten original procedural PNGs for J-54's wardrobe looks: two decks (Pixel
Shadow, Calculator Deck) sharing one card face, the Signal Argyle table, Pixel
Chips and two avatars (Pixel Clown, Red Terminal). Copied unchanged from the
approved preview `output/j54_theme_v10`, generated by
`scripts/generate_j54_theme.py`. No third-party images.

Catalog entries: `chaos_blackjack/cosmetics/catalog.py` (series `j54`);
prices: `cosmetic_price` rows in `chaos_blackjack/data/seed/default.sql`.
