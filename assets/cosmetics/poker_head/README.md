# Poker Head's House Collection (cosmetics)

Six original procedural PNGs that complete Poker Head's look, copied unchanged
from the approved preview `output/poker_head_theme_v3`, generated by
`scripts/generate_poker_head_theme.py`. No third-party images.

- `card_back_poker_head_gold.png`: rose field, gold diamond lattice and a broad
  gilded frame. Shares its outline with `card_front_poker_head`
  (deck `deck_poker_head_gold`, "Gilded Lattice").
- `chips_poker_head_{1,5,10,25}.png`: classic striped chips in white, red, deep
  blue and green with an ivory centre for the runtime value
  (`chips_poker_head`, "House Collection").
- `avatar_poker_head_j.png`: a gold serif J on dark green
  (`avatar_poker_head_j`, "Gold J").

The same run also redrew `table_poker_head.png` (two floral corners and two
side ornaments), which replaces the file in `assets/cosmetics/procedural/`.

Catalog entries: `chaos_blackjack/cosmetics/catalog.py` (series `poker_head`).
Until their own unlock rules are decided, the achievement Poker Face
(`chaos_blackjack/data/seed/default.sql`) rewards all of them.
