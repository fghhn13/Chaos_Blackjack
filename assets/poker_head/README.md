# Poker Head build icons

Approved on 2026-10-13: 41 item icons, comprising 36 Game-icons.net API silhouettes and five original code-drawn SVG selections.

Specification and per-item visual meanings: [POKER_HEAD_ART.md](../../docs/design/POKER_HEAD_ART.md).

- 256x256 transparent RGBA PNGs; old gold #B7A477; centered with 12% transparent margin.
- Filenames match the `ph_*` product IDs registered in the GUI asset manifest.
- [manifest.json](manifest.json) records sources, authors, selected variants, dimensions and SHA-256 hashes.
- [Attribution](../CREDITS.md) includes all third-party icon credits and original SVG provenance.
