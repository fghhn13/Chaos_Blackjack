# 🃏 混沌 21 点 · 玩家生存手册

> 普通 21 点：你和庄家斗智斗勇。
> 混沌 21 点：你和庄家斗智斗勇，而庄家背后还站着一个会偷偷改规则的 AI。祝你好运。

---

## 🚀 三秒开局

```bash
pip install -e ".[gui]"
python -m chaos_blackjack.gui
```

窗口弹出来就是主页。第一次玩点 **Start game** 给自己起个名字，接着在开局准备里选模式、点 **Start run**，你的赌徒生涯就开始了。

音效使用 Kenney 的 CC0 Casino 音效包，覆盖发牌、筹码、赢、输和成功生效的混沌效果。
总音量默认 **40%**。主页左下角的 **Settings** 里有 **Sound** 按钮，任何界面按 **M** 键也可以静音；
**+ / -** 每次调整 10%。静音时调整音量会保留静音，取消静音后恢复设定的音量。
也可以用 `python -m chaos_blackjack.gui --volume 0.3` 或 `--mute` 启动。
音量设置仅保留在本次运行中；没有音频设备时游戏仍可正常运行。命令行玩法不播放音效。

## 🎯 目标

- 你带着 **100** 块钱进场。
- 经典牌桌赚到 **300** 就算赢，可以潇洒离场；扑克头的牌桌要让**净资产达到 500**（见下文）。
- 资金低于 **10** 时已无法下最低注，本次挑战结束。

---

## 📜 规则速成（看完就算会了）

- 手里的牌越接近 **21** 越好，超过 21 就是**爆牌**，直接输。
- A 算 1 或 11（自动挑对你有利的），J/Q/K 都算 10。
- 每局最低下注 **5**，最多是你**当前资金的一半**。全押？不存在的，赌场替你的钱包操心。
- 庄家很死板：不到 17 点就一直抽，到 17 点就收手。
- **天生 21 点**（原始牌面 A 加 10/J/Q/K）：赔 **1.5 倍**！双方的天生 21 点都在混沌规则生效前结算；庄家要是也天生 21 点，就当无事发生。
- 庄家天生 21 点？那你连出手的机会都没有，这局直接结束。人生就是这样。
- 下注前可以逛**商店**：每次上架 3 种道具，每种只能买一个，**每 2 局换一批货**。买完至少得剩 10 筹码，才能下最低 5 筹码的注。

以上数字是默认配置。现在游戏通过 SQLite 的 **balance profile** 管理资金、下注范围、商店价格和规则参数，可用 `--profile NAME` 选择其他配置。其他配置下，以画面显示的下注范围、商品是否可买和规则说明为准；例如资金 40、最低下注 5、最多下注四分之一时，只能下 5～10，买东西后至少要剩 20 才能继续下注。存档会保留本次牌局使用的完整配置。

## 🎮 操作

| 我想…… | 鼠标 | 键盘 |

| 下注 | 左键点筹码加钱，右键点筹码减钱 | ↑ / ↓ 微调，Enter 发牌 |
| 逛商店（下注时） | 右下角 Shop | B 打开，1 / 2 / 3 购买，Esc 关闭 |

## 🌀 扑克头的牌桌（构筑玩法，重头戏）

在 **New run** 的牌桌列表里选 **Poker Head's Table**（扑克头的牌桌）。这张桌是**构筑玩法**：你一边打牌一边攒一套核心、永久增益和道具，扑克头则一轮比一轮更会改环境。

**目标：净资产达到 500。** 净资产 = 现金 + 还没到期的投资本金 − 所有还没还的借款。借来的钱不能直接让你通关，投资没到期的收益也不提前算。顶栏上面一行是现金（BANKROLL），下面一条是目标进度（GOAL）。

**开局二选一。** 扑克头先送你一份「见面礼」：两个核心选一个，或者干脆不要，多拿 **30** 筹码、整局不带核心。

| 核心 | 一句话 |
| --- | --- |
| 余裕条款 Room to Breathe | 你的爆牌上限 +1（22 才算爆） |
| 保本条款 Graceful Retreat | 投降只损失 20% |
| 近似满点 Almost Perfect | 开局天然结算之后，你的 20 和 22 都按 21 算 |
| 豪注礼遇 High Stakes | 加倍赢了再多赚 25% |
| 贵宾账户 Private Account | 商店多一格，并解锁理财产品 |

商店里的「改约函」可以之后换核心，已买的东西都保留。

**永久增益最多 2 件。** 每件只能装一份；满了再买会让你选一件替换，取消不花钱。下注前也可以在背包（Panel → Bag）里点一件永久增益**舍弃**，确认后腾出格位，不退款，它以后还可能再上架。右侧栏会用图标列出你的核心和永久增益。

**商店。** 每批 3 格（贵宾账户 4 格），每 2 轮补货，固定价格，可付 3 筹码刷新一次。越往后永久商品越常见。图标颜色分三类：**金色**是永久增益，**青绿**是消耗品，**紫蓝**是核心、理财和见面礼这类特殊商品。每件道具都写着能在什么时候用（下注前 / 你的回合），用不了时会告诉你原因。

**理财（需要贵宾账户）。** 稳息存单投 30 两轮后返 40；胜场债券投 20，三轮赢两轮返 45、否则返 10；波动股票投 30，两轮后一半机会返 90、否则归零；短借契约现在借 40，三轮后还 50。

**最低下注会涨。** 第 1–3 轮最低 5，之后每 3 轮升一档：10、15、20、30、40，再往后每 3 轮 +10。拖得越久越难。

**扑克头的环境规则。** 每轮在你购物和下注**之前**，扑克头可能新增或替换一条规则（也可能这轮按兵不动），同时最多 3 条。前几轮只是小改动，越往后越狠：

| 规则 | 人话翻译 |
| --- | --- |
| 牌点改写 | 某些牌固定按某个点数算，比如所有 7 都算 10 |
| 牌点偏移 | 某些牌每张 +1 / −1，比如红色牌 +1、黑色牌 −1；一张牌最少算 1 点 |
| 爆牌线 | 你的爆牌上限变低（比如 20），或者庄家的变高（比如 23）；你的核心和道具照样加在上面 |
| 平局归庄 | 点数相同算你输 |
| 庄家爆牌豁免 | 庄家爆了而你没爆，只算平局 |
| 提现阻挠 | 这一轮最多只能赚 N 筹码，多出来的作废（本金返还、贷款到账、回购不算赚） |
| 道具封禁 | 你下一次用消耗品只会解除封禁，道具白白消耗、没有效果；也可以等它过期 |
| 商店涨价 | 消耗品和永久增益涨价，理财和刷新费不变 |
| 玩家暗牌 | 你的第二张起手牌盖着，总点数也看不到，停牌后才翻开 |

- 规则显示在左侧栏，Panel → Rules 里能看到完整说明：作用对象、效果、还剩几轮（或一直生效）、怎么解除。
- 「条款撕除」可以永久清掉一条；「静默印章」让本轮所有规则失效（下一轮恢复）。被你清掉的规则类型会冷却一段时间，自然到期的也会暂时不再出现。
- 天然 21 点永远按原始两张牌判定，不受牌点规则影响。
- 屏幕上显示的点数**已经算上了所有规则和你的增益**，相信它就行。

**无模式的旧混沌局。** 命令行 `python -m chaos_blackjack.agent new --chaos`（不加 `--mode`）仍是旧版玩法：目标 300 筹码，混沌 AI 每局发牌后可能改一条旧规则（点数修改、大崩盘、奇偶混沌、花色之力、脆弱爆牌、反转爆牌、平局偏移）。

想让真正的大模型来当这个 AI？去看 [README](../README.md) 里的 “Real LLM” 一节。

**戳一下头像**：在扑克头的牌桌上，下注时、轮到你出牌时、查看本局结算时，都能点击左侧头像提问；商店打开时也可以。AI 会参考完整局面，包括暗牌、牌堆顺序、当前规则、资金、背包和商店的库存、价格与刷新时间，给一句建议。程序每次以 **50% 概率选择引导、50% 概率选择误导**，不会告诉你选了哪种；这是意图的概率，不保证建议有一半正确。它只说话，不会替你出牌、买东西或改规则。

提问后会出现 banner，显示动态的 **Chaos is thinking...**，挡住连点和出牌操作。回复后点 **Continue** 或按 **Enter** 继续；等待时按 **Esc** 可以确认返回菜单，不用等请求结束。离线模式给本地建议；真实 LLM 模式每次提问调用一次付费 API，失败后不会自动重试。

记忆功能已预留，但**默认关闭**：不会积累历史，也不会把记忆写入存档或发送给模型。目前没有玩家端的开启按钮。需要开启时，可先克隆默认 profile，再用 `python -m chaos_blackjack.data set NAME chaos.memory_enabled 1` 修改它，启动时选择这个 profile。`chaos.memory_limit` 设置最多保留多少条记录，默认 32；`chaos.guidance_probability` 可调整引导概率，默认 0.5。已开启的记忆和这些设置都会随存档恢复。

以下是经典牌桌的道具；扑克头的牌桌有自己的 41 件商品（见上文和图鉴），局外带入的这些道具在扑克头桌上会按对应的新道具生效（例如 Fate Oracle 变成「命运预言」）。

## 扑克头 Poker Head

仓库里新增了一位混沌庄家 **扑克头**：西装领结、脑袋是一把扇形展开的 A。
他永远彬彬有礼、不慌不忙，说话优雅得体，但从来不站在你这边。

- **出手风格**：偏爱"体面"的小动作，比如花色之力、奇偶混沌、平局判庄家、全体点数 −1，
  偶尔才会动用大崩盘和脆弱爆牌；也常常故意来一局平静局，让你放松警惕。
  他从不碰你的道具。整体比默认混沌 AI 稍微狠一点点。
- **表情**：8 种立绘会随局面切换，比如改规则时亮牌、你用道具时审视你、
  你赢了他会不悦、平局时一脸疑惑、被你戳头像时把牌藏到身后。
- **怎么和他玩**：`python -m chaos_blackjack.content play poker_head`
  （直接开桌，混沌模式，离线不收费）。命令行玩法：
  `python -m chaos_blackjack.agent new --pack poker_head --ai poker_head --chaos`。
  主菜单的 New run 里选 **Poker Head's Table** 即可和他对局。

## 玩家存档与局外成长

游戏一打开是主页：右上角是当前玩家的头像、名字和代币（点击打开 **Profile** 个人页），左侧菜单会告诉你下一步。
有未完成的 run 时，最醒目的是 **Continue run**，下面附带模式、回合和筹码；否则就是 **New run**。
再往下是 **Shop**（商店，原 Upgrades，用代币买局外升级）、**Collection**（图鉴）和 **Run history**（对局记录），
**Settings** 和 **Quit** 在左下角。再次打开游戏时会自动选中上次的玩家。

没有创建玩家时无法获得代币或购买升级：**Shop** 和 **Run history** 会带有 “Needs a player” 标签，
点击它们或右上角的 “No player yet” 会提示先创建玩家，并高亮 **Start game** 按钮（旁边显示 “Start here”）。

**Profile** 个人页有三个标签：
- **Overview**：头像、代币、成就和收藏进度，以及累计战绩（局数、胜场、回合、赢的手数、blackjack、最长连胜、最高筹码）；可以改名或换头像。
- **Wardrobe**（衣柜）：只用来切换。分 **牌组（卡背+牌面）/ 牌桌 / 筹码 / 头像** 四类，页签上显示收集进度（比如 Decks 3/4），
  只列出已拥有的装扮，点 **Equip** 立即换上；右侧小牌桌实时预览搭配效果。想要新装扮点 **More in the Shop** 去商店买。
  默认设置下**所有装扮都已解锁**（包括 J-54 的像素卡组、计算器卡组、格纹桌布、像素筹码和两款头像），可以直接装备；
  这个开关不改动你的收藏记录，关掉后（在克隆的 profile 里把 `meta.unlock_all_cosmetics` 设为 0）恢复真实的购买与成就解锁。
  装扮只改变外观，不影响任何规则和数值。
- **Achievements**（成就）：已解锁的排在前面，未解锁的显示进度条；隐藏成就解锁前显示 “???”。
  大多数成就奖励代币，少数还会送一套装扮。成就在 run 结算时判定，结算页会列出新解锁的成就，
  奖励的装扮可以直接点 **Equip**。

**Switch player** 进入 **Players** 页：3 个独立玩家槽位，**Play** 切换到该玩家并回到主页，空槽位可以 **Create player**，
删除前一定会确认。每个玩家的代币、升级、装扮和成就都是独立的。

**New run** 是独立的开局准备页：选择 **Classic Table**（经典牌桌：扑克头照规矩发牌，规则始终不变）或 **Poker Head's Table**（扑克头的牌桌：构筑玩法，目标净资产 500，留意每轮公布的环境规则），
中间会显示牌桌简介，并单独列出目标、下注范围、规则、荷官和赔率，方便比较；
查看模式规则和本局生效的永久升级，
勾选要携带的消耗品（每种勾选的道具带一份）。浏览和勾选都不会消耗道具，
真正点 **Start run** 时才扣除；如果还有未完成的 run，此时才会询问是否放弃它。
返回再进来，上次的选择会保留。
每局默认最多带 **2 种**消耗品，局外升级 **Bag Space** 可以扩到 3 种、4 种；**Reroll Pass** 让每局第一次刷新商店免费。
局外升级在所有模式通用；个别升级只属于某个模式，商店里会标 “XX ONLY”，开局准备页只列出当前模式能用的。

每个模式由一位混沌 AI 主持，有自己的混沌规则池、道具池和胜利目标。点 **Start run** 进入牌桌后，
主持 AI 会先说几句：随机的开场白、胜利目标、可能改哪些规则；一局结束时（赢或输）它也会随机说几句再进入结算。
每句话都会换一个表情。Enter / 点击翻页，Esc 跳过；**Continue run** 继续旧局时不会再说开场白。
第一次在 Poker Head 模式赢下一局（成就 **Poker Face**），会得到扑克头的牌组和牌桌。

每个区域下面再分 **Classic Table**（经典牌桌）和 Dealers（荷官，目前是 **Poker Head**），某位荷官在该区域没有东西时不显示。

牌桌按 Esc 会确认放弃并返回主页。历史页可翻页查看，长明细使用滚轮或 Page Up / Page Down 滚动。

## 本轮规则与默认庄家更新

两张牌桌都由扑克头主持，包含八种表情和对应台词：Poker Head's Table 上他会改环境规则，Classic Table 经典牌桌上他规规矩矩，台词也不一样。

以下是经典牌桌（以及命令行无模式的旧混沌局）的数值；扑克头牌桌的构筑玩法见上文「扑克头的牌桌」。

起始资金为 100，目标为 300；最低下注为 5，上限为当前资金的一半。资金不足 10 时结束本局；购买或刷新商店后也必须留下至少 10。

商店每两回合补货，三种商品；价格按补货时的当前资金计算，四舍五入，最低 1 筹码：peek 4%、danger_radar 6%、swap 2%、hole_card_hacker 3%、fate_oracle 8%、shield 5%。普通模式不出售 shield。每批货可刷新一次，费用为 3 筹码，刷新不重置补货计时；新商品按扣除刷新费后的资金定价。

起手 A 加 10/J/Q/K 的天然 21 在混沌规则生效前结算，双方同样保护。混沌使其他起手牌爆牌时立即判负；reverse_bust 则按平局结算。规则改变后的两张牌恰好为 21，不会额外获得天然 21 赔付。
