# 🃏 混沌 21 点 · 玩家生存手册

> 普通 21 点：你和庄家斗智斗勇。
> 混沌 21 点：你和庄家斗智斗勇，而庄家背后还站着一个会偷偷改规则的 AI。祝你好运。

---

## 🚀 三秒开局

```bash
pip install -e ".[gui]"
python -m chaos_blackjack.gui
```

窗口弹出来，点 **New Game**，你的赌徒生涯就开始了。

---

## 🎯 目标

- 你带着 **100** 块钱进场。
- 赚到 **400** 就算赢，可以潇洒离场。
- 输光了……那就只能在结局画面里对着空桌子发呆了。

---

## 📜 规则速成（看完就算会了）

- 手里的牌越接近 **21** 越好，超过 21 就是**爆牌**，直接输。
- A 算 1 或 11（自动挑对你有利的），J/Q/K 都算 10。
- 每局下注最多是你**当前资金的一半**。全押？不存在的，赌场替你的钱包操心。
- 庄家很死板：不到 17 点就一直抽，到 17 点就收手。
- **天生 21 点**（头两张就是 21）：赔 **1.5 倍**！庄家要是也天生 21 点，就当无事发生。
- 庄家天生 21 点？那你连出手的机会都没有，这局直接结束。人生就是这样。
- **连赢 2 局**，送你一个随机道具。

## 🎮 操作

| 我想…… | 鼠标 | 键盘 |
| --- | --- | --- |
| 下注 | 左键点筹码加钱，右键点筹码减钱 | ↑ / ↓ 微调，Enter 发牌 |
| 再要一张（要牌） | Hit | H |
| 到此为止（停牌） | Stand | S |
| 赌一把大的（加倍） | Double | D |
| 认怂（投降） | Surrender | R |
| 下一局 | Next Round | Enter |
| 逃回主菜单 | — | Esc |
| 全屏 | — | F11 |

- **加倍**：下注翻倍，只再发你**一张**牌，然后自动停牌。刚拿到两张牌时才能用。
- **投降**：拿回一半下注走人。同样只能在刚拿到两张牌时用。投降不丢人，丢人的是爆牌。

## 🌀 混沌模式（重头戏）

在主菜单打开 **Chaos Mode: ON**，混沌 AI 就会入场。每局发完牌后，它**可能**会悄悄改一条规则：

| 规则 | 人话翻译 |
| --- | --- |
| 点数修改 Value Shift | 每张牌的点数都变了（比如全部 −1）。数学老师哭了 |
| 大崩盘 Great Crash | 10、J、Q、K 全部只值 1 点。大牌瞬间变废铁 |
| 奇偶混沌 Odd-Even Chaos | 2/4/6/8 每张 +2，3/5/7/9 每张 −1 |
| 花色之力 Suit Power | 红色花色 +1，黑色花色 −1。颜色即正义 |
| 脆弱爆牌 Fragile Bust | 超过 **18** 就爆！对庄家也一样，大家一起提心吊胆 |
| 反转爆牌 Reverse Bust | 爆牌不再自动判输：立刻摊牌比点数，大的赢 |
| 平局偏移 Tiebreaker Shift | 平局不再是平局，判给某一方（多半不是你） |

另外：
- 它每局**最多出手一次**，生效的规则会显示在屏幕上，不会暗箱操作。
- 屏幕上显示的点数**已经算上了混沌规则**，相信它就行，不用自己心算。
- 它有时会**用掉你背包里的道具**。没错，它会偷你的东西。

想让真正的大模型来当这个 AI？去看 [README](../README.md) 里的 “Real LLM” 一节。

## 💡 生存小贴士

1. 自己 11 点、庄家明牌很小的时候，**加倍**很香。
2. 自己 16 点、庄家明牌是 10 或 A 的时候……可以认真考虑一下**投降**。
3. 庄家明牌是 4、5、6 时，他很容易爆牌。你稳住别乱要牌，让他自己翻车。
4. 混沌规则一出，先看清屏幕上的新点数再动手。别用昨天的经验打今天的牌。
5. 别想着一把翻身。你最多只能押一半，赌场早就替你想好了。

## 🛠️ 遇到问题？

- **画面全是程序画的简笔画？** 正常，那是占位图。美术素材放进 `assets/` 文件夹，按 **F5** 就能替换。
- **开了真实 AI 后画面卡几秒？** AI 正在思考怎么坑你，这个卡顿以后会修。
- **还是更喜欢命令行？** 输入 `python cli/main.py`，体验复古风。
