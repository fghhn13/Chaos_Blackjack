# 🃏 混沌 21 点 · 玩家生存手册

> 普通 21 点：你和庄家斗智斗勇。
> 混沌 21 点：你和庄家斗智斗勇，而庄家背后还站着一个会偷偷改规则的 AI。祝你好运。

---

## 🚀 三秒开局

```bash
pip install -e ".[gui]"
python -m chaos_blackjack.gui
```

窗口弹出来就是主页。第一次玩点 **Start game** 给自己起个名字，接着在开局准备里选模式、点 **Start run**，你的赌徒生涯就开始了。

音效使用 Kenney 的 CC0 Casino 音效包，覆盖发牌、筹码、赢、输和成功生效的混沌效果。
总音量默认 **40%**。主页左下角的 **Settings** 里有 **Sound** 按钮，任何界面按 **M** 键也可以静音；
**+ / -** 每次调整 10%。静音时调整音量会保留静音，取消静音后恢复设定的音量。
也可以用 `python -m chaos_blackjack.gui --volume 0.3` 或 `--mute` 启动。
音量设置仅保留在本次运行中；没有音频设备时游戏仍可正常运行。命令行玩法不播放音效。

## 📜 规则速成（看完就算会了）

- 手里的牌越接近 **21** 越好，超过 21 就是**爆牌**，直接输。
- A 算 1 或 11（自动挑对你有利的），J/Q/K 都算 10。
- 每局下注最多是你**当前资金的一半**。全押？不存在的，赌场替你的钱包操心。
- 庄家很死板：不到 17 点就一直抽，到 17 点就收手。
- **天生 21 点**（头两张就是 21）：赔 **1.5 倍**！庄家要是也天生 21 点，就当无事发生。
- 庄家天生 21 点？那你连出手的机会都没有，这局直接结束。人生就是这样。
- 下注前可以逛**商店**：每次上架 3 种道具，每种只能买一个，**每 2 局换一批货**。买完至少得剩 2 块钱下注——赌场不卖东西给穷光蛋。价格目前是随便填的，还没调平衡。

以上数字是默认配置。现在游戏通过 SQLite 的 **balance profile** 管理资金、下注范围、商店价格和规则参数，可用 `--profile NAME` 选择其他配置。其他配置下，以画面显示的下注范围、商品是否可买和规则说明为准；例如资金 40、最低下注 5、最多下注四分之一时，只能下 5～10，买东西后至少要剩 20 才能继续下注。存档会保留本次牌局使用的完整配置。

## 🎮 操作

| 我想…… | 鼠标 | 键盘 |
| --- | --- | --- |
| 下注 | 左键点筹码加钱，右键点筹码减钱 | ↑ / ↓ 微调，Enter 发牌 |
| 逛商店（下注时） | 右下角 Shop | B 打开，1 / 2 / 3 购买，Esc 关闭 |
| 问混沌 AI 一句 | 点击左侧 Chaos 头像 | 回复后 Enter / Continue 关闭 banner |
| 再要一张（要牌） | Hit | H |
| 到此为止（停牌） | Stand | S |
| 赌一把大的（加倍） | Double | D |
| 认怂（投降） | Surrender | R |
| 下一局 | Next Round | Enter |
| 逃回主页（会先确认，并放弃本局） | — | Esc |
| 全屏 | — | F11 |

- **加倍**：下注翻倍，只再发你**一张**牌，然后自动停牌。刚拿到两张牌时才能用。
- **投降**：拿回一半下注走人。同样只能在刚拿到两张牌时用。投降不丢人，丢人的是爆牌。

## 🌀 混沌模式（重头戏）

在 **New run** 的模式列表里选 **Chaos**，混沌 AI 就会入场。每局发完牌后，它**可能**会悄悄改一条规则：

| 规则 | 人话翻译 |
| --- | --- |
| 点数修改 Value Shift | 每张牌的点数都变了（比如全部 −1）。数学老师哭了 |
| 大崩盘 Great Crash | 10、J、Q、K 全部只值 1 点。大牌瞬间变废铁 |
| 奇偶混沌 Odd-Even Chaos | 2/4/6/8 每张 +2，3/5/7/9 每张 −1 |
| 花色之力 Suit Power | 红色花色 +1，黑色花色 −1。颜色即正义 |
| 脆弱爆牌 Fragile Bust | 超过 **18** 就爆！对庄家也一样，大家一起提心吊胆 |
| 反转爆牌 Reverse Bust | 爆牌不再自动判输：立刻摊牌比点数，大的赢 |
| 平局偏移 Tiebreaker Shift | 平局不再是平局，判给某一方（多半不是你） |

另外：
- 它每局**最多出手一次**，生效的规则会显示在屏幕上，不会暗箱操作。
- 屏幕上显示的点数**已经算上了混沌规则**，相信它就行，不用自己心算。
- 规则改了点数，A 也会跟着变（比如 −1 时 A 算 10 或 0），但它依然会在你快爆牌时自动“缩水”救你一命。
- 它有时会**用掉你背包里的道具**。没错，它会偷你的东西。

想让真正的大模型来当这个 AI？去看 [README](../README.md) 里的 “Real LLM” 一节。

**戳一下头像**：混沌模式下，下注时、轮到你出牌时、查看本局结算时，都能点击左侧头像提问；商店打开时也可以。AI 会参考完整局面，包括暗牌、牌堆顺序、当前规则、资金、背包和商店的库存、价格与刷新时间，给一句建议。程序每次以 **50% 概率选择引导、50% 概率选择误导**，不会告诉你选了哪种；这是意图的概率，不保证建议有一半正确。它只说话，不会替你出牌、买东西或改规则。

提问后会出现 banner，显示动态的 **Chaos is thinking...**，挡住连点和出牌操作。回复后点 **Continue** 或按 **Enter** 继续；等待时按 **Esc** 可以确认返回菜单，不用等请求结束。离线模式给本地建议；真实 LLM 模式每次提问调用一次付费 API，失败后不会自动重试。

记忆功能已预留，但**默认关闭**：不会积累历史，也不会把记忆写入存档或发送给模型。目前没有玩家端的开启按钮。需要开启时，可先克隆默认 profile，再用 `python -m chaos_blackjack.data set NAME chaos.memory_enabled 1` 修改它，启动时选择这个 profile。`chaos.memory_limit` 设置最多保留多少条记录，默认 32；`chaos.guidance_probability` 可调整引导概率，默认 0.5。已开启的记忆和这些设置都会随存档恢复。

## 💡 生存小贴士

1. 自己 11 点、庄家明牌很小的时候，**加倍**很香。
2. 自己 16 点、庄家明牌是 10 或 A 的时候……可以认真考虑一下**投降**。
3. 庄家明牌是 4、5、6 时，他很容易爆牌。你稳住别乱要牌，让他自己翻车。
4. 混沌规则一出，先看清屏幕上的新点数再动手。别用昨天的经验打今天的牌。
5. 别想着一把翻身。你最多只能押一半，赌场早就替你想好了。

## 🛠️ 遇到问题？

- **画面全是程序画的简笔画？** 正常，那是占位图。美术素材放进 `assets/` 文件夹，按 **F5** 就能替换。
- **开了真实 AI 后要等几秒？** AI 会在后台思考，牌桌显示动态的 “The Chaos AI is thinking...” 提示。等待期间不能出牌，但画面会持续刷新，仍可按 **Esc** 返回菜单或按 **F11** 切换全屏。返回菜单不用等请求完成。
- **还是更喜欢命令行？** 输入 `python cli/main.py`，体验复古风。

祝你赢到 400 块，然后头也不回地离开这张桌子。 🎲

## 扑克头 Poker Head

仓库里新增了一位混沌庄家 **扑克头**：西装领结、脑袋是一把扇形展开的 A。
他永远彬彬有礼、不慌不忙，说话优雅得体，但从来不站在你这边。

- **出手风格**：偏爱"体面"的小动作，比如花色之力、奇偶混沌、平局判庄家、全体点数 −1，
  偶尔才会动用大崩盘和脆弱爆牌；也常常故意来一局平静局，让你放松警惕。
  他从不碰你的道具。整体比默认混沌 AI 稍微狠一点点。
- **表情**：8 种立绘会随局面切换，比如改规则时亮牌、你用道具时审视你、
  你赢了他会不悦、平局时一脸疑惑、被你戳头像时把牌藏到身后。
- **怎么和他玩**：`python -m chaos_blackjack.content play poker_head`
  （直接开桌，混沌模式，离线不收费）。命令行玩法：
  `python -m chaos_blackjack.agent new --pack poker_head --ai poker_head --chaos`。
  目前主菜单的 New run 还不能选择庄家，会在开局准备页加入庄家选择后开放。

## 本地扩展道具和混沌 AI

仓库自带示例内容包。运行 `python -m chaos_blackjack.content play example`
即可载入示例道具、商店商品和混沌 AI，直接打开牌桌。玩家回合按 **I** 打开完整
道具列表，查看说明并按 **Enter** 使用。示例道具需要至少
三张手牌，能丢弃最后一张牌；已经爆牌结算后不能再使用。

内容包默认使用离线 AI；显式添加 `--llm` 才切换到收费模型。命令行玩法可添加
`--agent`。玩家和混沌 AI 共用道具效果执行器，AI 使用 Swap 也会实际换牌；
玩家使用 Shield 会驱散当前生效的规则，不会阻止之后的混沌操作。新增内容的生成、校验、测试和载入步骤见
[扩展流程文档](CONTENT_WORKFLOW.md)。

内容包道具也通过商店获取，价格来自所选 balance profile；连胜不再赠送内容包道具。未加载的插件道具不会出现在货架。生成的新内容包需先将 `shop.sql` 安装到可编辑的 balance profile，示例包已内置 20 筹码价格。

## 玩家存档与局外成长

游戏一打开是主页：右上角是当前玩家和代币（点击可切换玩家），左侧菜单会告诉你下一步。
有未完成的 run 时，最醒目的是 **Continue run**，下面附带模式、回合和筹码；否则就是 **New run**。
再往下是 **Upgrades**（局外升级）、**Collection**（图鉴）和 **Run history**（对局记录），
**Settings** 和 **Quit** 在左下角。再次打开游戏时会自动选中上次的玩家。

没有创建玩家时无法获得代币或购买升级：**Upgrades** 和 **Run history** 会带有 “Needs a player” 标签，
点击它们或右上角的 “No player yet” 会提示先创建玩家，并高亮 **Start game** 按钮（旁边显示 “Start here”）。

**Players** 页有 3 个独立玩家槽位：**Play** 切换到该玩家，空槽位可以 **Create player**，
重命名和删除也只在这里操作，删除前一定会确认。

**New run** 是独立的开局准备页：选择 Classic / Chaos，查看模式规则和本局生效的永久升级，
勾选要携带的消耗品（每种勾选的道具带一份）。浏览和勾选都不会消耗道具，
真正点 **Start run** 时才扣除；如果还有未完成的 run，此时才会询问是否放弃它。
返回再进来，上次的选择会保留。

**Upgrades** 页按分类展示永久升级的等级与下一次价格，以及消耗品数量；价格和效果来自
balance profile。胜利或失败后会显示代币明细并返回主页，放弃 run 不获得代币。
run 在开始和允许保存的操作后自动保存，关闭游戏后可从主页的 **Continue run** 继续。
牌桌按 Esc 会确认放弃并返回主页。历史页可翻页查看，长明细使用滚轮或 Page Up / Page Down 滚动。

所有菜单都支持键盘：上下键或 Tab 移动焦点，Enter / 空格确认，Esc 返回。

游戏不再提供不记录进度的快速游玩，每一局都属于某个玩家。
主页的 **Collection**（图鉴）：按规则、道具、模式和 AI 分类查看说明，数值随所选
balance profile 更新。道具和规则提供固定发牌的动画演示；**空格**暂停，**R**重播，
**左右键**逐帧查看，滚轮或 **Page Up / Page Down** 滚动说明。演示使用离线模型，
不会收费，也不会消耗代币或改变玩家进度。也可运行
`python -m chaos_blackjack.gui --scene codex` 直接打开图鉴。
操作及开发预览详见 [META_GUI.md](META_GUI.md)。
