# Poker Head：局内构筑设计概览

日期：2026-10-13  
状态：已实现首版（2026-10-13）；数值和概率仍需模拟验证。

适用于 Poker Head 的混沌桌（chaos）。具体效果、使用阶段、替换和结算统一见 [道具与增益效果明细](POKER_HEAD_EFFECTS.zh-CN.md)。

新版混沌环境的完整规则文本与逐步增强的离线庄家方案见 [混沌规则与离线 Agent 设计稿](POKER_HEAD_CHAOS_RULES_AND_AGENT.zh-CN.md)。该稿包含满位替换、通用牌点改写、收益封顶、消耗品抵消封禁、商店涨价与玩家暗牌，已接入游戏。

## 1. 构筑方向

玩家通过核心选择、有限永久增益位、消耗品和金融产品形成整局打法。胜利目标已确认为 **当前净资产达到500**（现金＋未到期投资本金－全部应付债务），最低下注逐步上涨，庄家的环境规则最多同时三条、随回合逐步增强。记账口径、代码搭建与报价见 [实施计划与定价](POKER_HEAD_IMPLEMENTATION_PLAN.zh-CN.md)。

| 流派 | 当前方向 |
|---|---|
| 多牌 | 核心提供爆牌余裕（+2），永久商品提供多牌奖励和 J/Q/K 小点结算。 |
| 投降 | 核心让要牌后仍可投降；永久商品降低损失、储存追偿机会，并让下一轮第一张起手牌成为 A。 |
| 控点 | 核心每轮可换一手起手牌；永久商品把 20、22 认定为 21、换牌争取满点高收益，并能把庄家起手天然 21 判给自己。 |
| 双倍 | 核心让要牌后仍可加倍；永久商品加大加倍收益、分担失败损失、自动翻开高点庄家暗牌，并用回购券调动资金。 |
| 金融 | 核心解锁金融产品并增加商店格；永久商品提供采购折扣、投资收益加成和额外免费刷新。 |

## 2. 开局选择与转型

- 「庄家的见面礼」随机给出两个不同核心，玩家可选其中一个。
- 也可以两者都不要，改拿额外初始筹码 **+30**。按“本局没有核心”处理，整局保持无核心，普通商品仍可买。
- 有核心时最多一个，核心不占永久增益位；对应流派商品出现概率提高。
- 商店「改约函」可在下注前提供两个不同的新核心供选择，更换不清空永久商品、道具和合同。
- 候选固定，查看或读档不重抽。选择无核心启动资金的整局不生成改约函。
- 退出金融核心会撤去核心提供的额外商店格，新金融产品不能买入；已有金融合同继续结算。

## 3. 有限永久增益位

永久增益位为 **2 位**（余额档 `mode.chaos.build_slots`）。

- 同名最多装备一件，不能无限叠加或重复购买升级。
- 满位购买时选择一件旧商品替换，确认后才扣款。
- 被替换商品停止提供效果，不退款、不进入备用仓库；以后可重新出现。
- 下注前可在背包主动舍弃一件永久商品：确认后生效，不退款，腾出格位，以后可能重新上架。
- 已结算收益不撤销，已用次数不因重新装备而重置。
- 金融的折扣、投资加成、免费刷新也各占一位；金融核心的额外商店格不占位。

## 4. 商店成长

分别控制商品类别概率和核心流派偏向：

| 回合 | 自由商品格出现永久商品的概率（首版定值） |
|---|---:|
| 1–3 | 20% |
| 4–6 | 30% |
| 7 及以后 | 40% |

每批货架保留至少一格泛用消耗品。同类别中当前核心对应商品按基础权重 ×2，其他商品 ×1。无核心时没有流派加权。已装备永久商品排除，空缺从其他允许类别补足。

金融核心增加一格；免费刷新来自永久商品「优先换货」，旧的一次性免费刷新券和额外付费刷新增益不再单独保留。

测试开关 `mode.chaos.unlock_all`（默认关闭）：打开后一次上架全部商品、理财不需要贵宾账户、不能刷新，用于检查全部条目。

## 5. 使用阶段与收益兑现

- 永久商品只在下注前装备或替换；核心和永久被动效果自动触发。
- 消耗品逐项区分下注前、玩家行动中，禁止在已经结算后补救。
- 「命运预言」在下注前查看起手发完后牌堆顶部的两张牌。
- 「王牌归位」在行动中把下一张 A 移到牌堆顶；「备用袖牌」提供免费换牌，「借花献佛」在开局转移庄家的天然 21 胜利。
- 「原价回购券」在下注前回收一件消耗品，返还该件的实际买入原价；达到通关资金可直接触发整局胜利。
- 「无损退场券」不生成追偿记录；不能通过免赔投降再领取未经折扣的退场费用。

- 图标按类别着色：永久增益为金色，消耗品为青绿，核心、理财产品和见面礼、改约函等系统道具为紫蓝；物品格、商店卡片和选择框的边框同色。
- 顶栏上方是现金（BANKROLL），下方是目标进度条（GOAL：净资产 / 500）。
- 右侧栏最上方是牌堆，下面以图标显示核心和永久增益（Build x/2），并显示最低下注和庄家当前阶段。
- 核心选择、满位替换、目标选择和舍弃确认都使用同一个选择框；可取消的选择取消后不扣款。
- 每件道具标明使用阶段；不可用时显示原因。环境规则以卡片显示名称、作用对象、效果、剩余回合和解除方式。

## 7. 当前目录与后续验证

本版 **43 个条目**：5 个核心、18 种永久商品、16 种消耗及管理道具（新增爆牌保险）、4 种金融产品。永久商品分布为多牌4、投降4、控点4、双倍3、金融3（2026-10-14：核心改为操作类，原核心保本条款、近似满点、豪注礼遇降为永久商品，延迟退场、追加下注权升为核心，新增核心换一手牌）；明牌审计归双倍，败后王牌归投降。所有条目的效果明细均附有商店／图鉴描述文案。

强度数值为首版定值，待模拟验证：五牌额外奖励、开局额外资金、采购折扣、理财净收益加成，以及满点彩金的收益倍率见效果明细。J/Q/K 按 5 点结算、王牌归位针对 A 的解释已在讨论中确认。

价格、最低下注曲线、净资产口径与清算、混沌叠加顺序已确定并实现。后续用模拟器验证局长，以及追偿、满点大奖、加倍减损、金融组合和环境规则对各流派收益的影响。
